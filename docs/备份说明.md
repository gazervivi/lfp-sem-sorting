## 二、runs/ 目录结构（每个实验目录内含）

```
runs/<run_name>/
├── config.json            实验配置（骨干/学习率/种子/协议路径等，完整可复现）
├── training_log.txt       逐 epoch 训练日志
├── per_epoch_metrics.csv  逐 epoch 指标（loss/acc/F1/耗时）
├── curves.png             训练曲线
├── best.pt                最优权重（1.4GB 总量的大头）
├── cm_val.png / cm_test.png   混淆矩阵
├── predictions_val.csv    val 集 tile 级预测（含四类概率）
├── predictions_test.csv   test 集 tile 级预测（含四类概率）
└── metrics.json           最终指标（含分类别 P/R/F1）
```

**实验目录分组**

| 前缀 | 含义 |
|---|---|
| `e1_P1_*` | 协议 P1（tile 级随机划分，文献做法）5 个骨干 |
| `e1_P2_*` | 协议 P2（图像级划分）5 个骨干 |
| `blocked_*` | 协议 P3（空间块划分，test 与 train 最小间距 90.1 µm） |
| `kfold_resnet50_f1..5` / `kfold_efficientnet_b0_f1..5` | 5 折交叉验证各折 |
| `kfold_merged_*` | 各折合并后的全覆盖评测结果 |
| `e2_*` | E2 聚合决策 + 拒判（risk-coverage）分析 |
| `e3_*` | E3 HiResCAM + 带随机对照的 AOPC；`cam_overlays/` 内 24 张叠加图 |
| `e4_resnet50/` | E4 t-SNE 特征空间 + 跨模型错误交集 |
| `figures/` | 汇总图表（协议落差瀑布图、骨干对比、主表） |

## 三、核心结果速览

| 协议 | 测试图数 | ResNet50 | EfficientNet-B0 |
|---|---|---|---|
| P1 tile 级随机 | 173 | 99.47% | 100.00% |
| P2 图像级 | 36 | 96.18% | 96.88% |
| P3 空间块级 | 35 | 98.93% | 98.75% |
| **KF 5 折全覆盖** | **176** | **97.83%** | **97.94%** |

- P1 使 **100% 的原图跨集泄漏**；相对 KF 高估 1.64–2.06 pp
- **P3（最严格）反而高于 P2** → 图像级划分在本数据集上已足够保守，P2 低分源于抽样波动
- KF 全覆盖：图像级 173/176 = 98.30%，**3 个错误样本全部属于 C 类**，两个为危险的 C→A
- 拒判：EffNet-B0 阈值 0.9 → 覆盖率 94.4% 时精度 100%

## 四、如何恢复与复现

```bash
# 1. 解包
tar -xzf lfp_backup_20260930.tar.gz -C /root/

# 2. 重建环境（约 5 分钟）
/opt/Anaconda3/bin/python -m venv /root/lfp/venv
/root/lfp/venv/bin/pip install -U pip -i https://pypi.tuna.tsinghua.edu.cn/simple
/root/lfp/venv/bin/pip install torch torchvision timm scikit-learn matplotlib pandas tqdm pillow numpy \
    -i https://pypi.tuna.tsinghua.edu.cn/simple

# 3. 只重做推理（无需重训）：复用已存的 best.pt
cd /root/lfp && /root/lfp/venv/bin/python finish_run.py --run /root/lfp/runs/<run_name>

# 4. 重出图表
/root/lfp/venv/bin/python report_results.py /root/lfp/runs
/root/lfp/venv/bin/python make_figures.py --runs-dir /root/lfp/runs --out /root/lfp/runs/figures
```

## 五、注意事项

1. **`best.pt` 含 pickled 配置对象**，加载时必须 `torch.load(..., weights_only=False)`
   （PyTorch ≥2.6 默认值为 True，否则报 `UnpicklingError`）；
2. `data/v2/splits/` 下的划分 CSV 是**可复现性的核心**，任何重训都必须引用同一份文件；
3. 非交互式 SSH 下 PATH 无 python，所有脚本须用 `/root/lfp/venv/bin/python` 绝对路径；
4. `data/raw/` 与本地 `原始图像/2026.2.9-XH/` 内容一致，如已有本地副本可不必重复存储。
